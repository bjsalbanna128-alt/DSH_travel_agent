# 交通方案进入路书和预算

## 原因与目标

编译器没有接收交通 Agent 的输出，展示的交通和预算可能与交通节点不同。

## 范围、影响与验收

按交通 Agent 的日期映射城际与城内段。城际明确日期优先，旧格式按去程首日、返程末日处理。当天只保留有效交通段。编译以实际分日费用估算总预算，票价按人估算；手动编辑保留交通费用。

## 验证计划

模拟两种 Agent 输出，核对分日交通、多人费用和超预算提示。

## 验证结果

模拟交通 Agent 和编译器验证了分日映射、多人票价计费和超预算提示。浏览器验证了两人交通共 6 元，手动保存后仍为 6 元，行程总额仍为 146 元。票价是估算，真实模型与票价来源未联调。
